## 一、美术风格定位与视觉规范

### 1. 核心基调
- **整体风格**：**蒸汽末世 + 暗黑克苏鲁奇幻的 2D 手绘图小说风格（Graphic Novel Game Art）**。
- **视觉关键词**：锈铁、硫火、港雾、盐晶、古老机械、残破龙骨、死星日蚀、深渊血誓。
- **剪影法则**：人物与敌怪必须具备棱角分明、重心明确的**外部硬剪影**。在战斗列表中缩小至 40×40 的单位头像框或手机窄屏下，依然能单凭外轮廓瞬间识别身份。

### 2. 色彩哲学与调色板
| 色彩类型 | 色值 | 视觉含义与应用场景 |
|---|---|---|
| **底色基石** | `#0a0c0f` ~ `#1e2630` | 炭灰、焦黑玄武岩、冷铅色阴影，构成画面的深沉基底 |
| **港雾冷青** | `#2ec4b6` / `#4f9e98` | 潮汐、海雾、锈铜绿、冷却金属，主要用于港口与机械场景 |
| **硫火赤金** | `#e5a50a` / `#ffd43b` | 黄铜齿轮、马灯暖光、高压电弧、金币与珍贵契约 |
| **余烬炽橙** | `#ff6b35` / `#ff9f43` | 炉火、熔岩重锤、灼烧轨迹、酒馆温暖核心 |
| **誓痕血红** | `#e03131` / `#be526a` | 鲜血誓印、议院红旗、受击撕裂、公证印泥 |
| **秘术冷紫** | `#9775fa` / `#a596b8` | 回响声波、盲眼秘术、死星日蚀、虚空裂隙 |
| **绝对零蓝** | `#4dabf7` / `#83b4b2` | 冰封盐矿、永冻水核、绝对零度霜晶 |

### 3. 交付规范与严苛红线
1. **纯净无字原则（绝对解耦）**：原画插图内**严禁绘制任何文字、卡牌名称、费用数字、攻击力数值或 UI 边框**。所有数值与文本均由前端代码动态渲染，确保多语言本地化与平衡调整无缝进行。
2. **格式与通道**：
   - 角色、怪物、道具图标一律交付 **透明背景 PNG 或无损 WebP**；
   - 场景与战斗大背景交付高质量 **WebP 或 JPG**；
   - 必须保留可编辑源文件（Layered PSD 或 CLIP Studio 格式，分层包含线稿层、光影层、底色层）。
3. **命名契约**：严格与代码内数据 ID 完全一致，全部小写下划线（例如 `c_strike_fire.webp`、`e_h_rust_harbormaster.webp`），杜绝中文或自定义随性命名。

## 三、前端工程契约与架构设计规范

### 1. 卡框（Card Frame）与插画窗口解耦
- 插画仅产出 `512×384`（4:3 比例）的内容图，主体收拢在内圈安全区。
- 前端使用 4 套通用矢量/切片卡框进行容器封装：
  - **攻击牌（Attack）**：铁红金属外框 + 锯齿磨损边角（`--t-attack: #c0392b`）
  - **技能牌（Skill）**：冷蓝铸铁外框 + 螺栓铰链边角（`--t-skill: #1c6ea4`）
  - **能力牌（Power）**：秘术暗金外框 + 齿轮符文雕饰（`--t-power: #6c3fa0`）
  - **诅咒牌（Curse）**：焦黑腐化外框 + 荆棘破裂纹路（`--t-curse: #3a3244`）

### 2. 渐进式优雅降级（Fallback）机制
在所有美术资源分批制作和接入过程中，代码使用原生优雅降级，确保永远不会破图：
```javascript
// 卡牌插画优雅降级
<img class="card-art-img" 
     src={`/assets/cards/${card.id}.jpg`} 
     onerror="this.onerror=null; this.src='/assets/cards/fallback.svg';" />

// 敌人与角色头像优雅降级
const glyphNode = (c.art || c.portrait)
  ? el('img', { class: 'cbt-glyph-img', src: c.art || c.portrait, alt: c.name })
  : el('span', { text: c.glyph || '?' });
```

### 3. 前端轻量微动效规范（无需骨骼动画实现跃升）
- **常态呼吸微浮动**：
  ```css
  @keyframes idleBreath {
    0%, 100% { transform: translateY(0); }
    50% { transform: translateY(-4px); }
  }
  .combatant:not(.dead) { animation: idleBreath 3.6s ease-in-out infinite; }
  ```
- **受击白闪与震颤**：
  ```css
  .combatant.flash-hit {
    filter: brightness(2.8) contrast(1.2);
    animation: shake 0.32s cubic-bezier(.36,.07,.19,.97);
  }
  ```
- **首领高危外发光**：
  ```css
  .combatant.big {
    filter: drop-shadow(0 0 14px rgba(255, 107, 53, 0.45));
  }
  ```
