# 🏮 焰契 · 锈锚酒馆

> 一款把 **肉鸽跑图 / 回合制卡牌对战 / 酒馆经营** 缝在一起的浏览器游戏。
> 纯原生 ES Module + 零依赖，Node 起一个静态服务器就能玩。

```bash
node server.js
# 打开 http://127.0.0.1:5173
```

> 必须通过 HTTP 访问（用到 ES Module，`file://` 会被浏览器的 CORS 策略拦下）。

自检（三件套，全部无需浏览器）：

```bash
npm run check          # 一次跑完下面三步
node tools/validate.js     # 数据引用完整性 + 60 场无头战斗模拟
node tools/importcheck.js  # ES Module 导入图完整性
node tools/uitest.js       # 最小 DOM 桩里把全部界面与完整远征流程跑一遍
```

---

## 一、这是什么

灰烬潮每隔一夜涨高一寸。你是锈锚酒馆最后一个老板。
一共 **6 夜**，**3 盏灯芯**——每失败一次灭一盏，灯芯耗尽，酒馆沉没。

| 层 | 内容 |
|---|---|
| **经营** | 酒馆跨局保留。设施、员工、局外升级、图鉴解锁。夜里「闭门经营」可赚被动收入，但潮水不等人。 |
| **肉鸽** | 每夜一次远征：选旅者 → 3 幕分支地图 → 首领 → 结算印记。种子化生成，可复现。 |
| **卡牌对战** | 3 能量 / 5 抽牌 / 格挡系统 / 27 种状态 / 敌人多阶段意图预告 / 40 件遗物钩子。 |
| **构筑** | 战后三选一、事件拿牌或拆牌、篝火升级或烧牌、商店洗牌、诅咒牌作为代价。 |

## 二、核心循环

```
        ┌──────────────── 酒馆（经营）────────────────┐
        │  设施升级 / 雇佣员工 / 局外升级 / 图鉴解锁    │
        │        「闭门经营」→ 收入 + 潮汐 -1 灯芯     │
        └───────────────┬────────────────────────────┘
                        │  「出发远征」
              ┌─────────▼──────────┐
              │  选择旅者（5 位）    │
              └─────────┬──────────┘
        ┌───────────────▼────────────────────────────┐
        │  第 N 幕：分支地图                         │
        │   ⚔战斗  ☗精英  ?异象  ⌂商队  ▲篝火  ◆宝库 │
        │              每层结束发放：卡牌/金币/药水/遗物 │
        └───────────────┬────────────────────────────┘
                        │  击败首领
              ┌─────────▼──────────┐
              │  结算 → 灰烬印记    │ → 回酒馆，进入下一夜
              └────────────────────┘
```

## 三、系统一览

### 战斗
- 每回合 3 能量、抽 5 张，攻击先扣格挡再扣血。
- **格挡**回合结束清零（除非有壁垒）。
- **状态 27 种**：`力量/敏捷/易伤/虚弱/脆骨/中毒/灼烧/荆棘/再生/神器/金属化/仪式/虚化/缠绕/壁垒/回响/专注/坚毅/超载/标记/束缚/迅捷/暴怒/蚀骨/空壳/静电/帷幕/汲取/碎裂`
  - 中毒无视格挡且逐层 -1；灼烧无视格挡且不衰减
  - 荆棘反弹攻击；神器抵消负面状态；仪式/金属化/再生在回合结算自动生效
- **敌人意图**在玩家回合开始时公布，含伤害数字与台词。精英与 Boss 有多阶段。
- **遗物 40 件**，13 个触发钩子（战斗开始 / 回合开始结束 / 出牌 / 攻击 / 击杀 / 商店 / 进节点 / 受伤 …）。

### 牌组
- 122 张卡牌，4 种类型（攻击 / 技能 / 力量 / 诅咒），5 档稀有度。
- 每张牌可升级；升级有 3 档变体（降费 / 提数值 / 多一层效果）。
- 机制覆盖：多段、随机目标、消耗、虚无、起手、弃牌堆操纵、牌库检索、条件牌、状态扩散、代价牌。
- 30+ 张带 `灰烬印记` 解锁，属于跨局永久内容。

## 五、操作

| 键 | 作用 |
|---|---|
| `1`~`9` | 打出对应手牌 |
| `E` / `空格` | 结束回合 |
| `D` | 查看牌组 |
| `Esc` | 关闭弹窗 |

## 六、扩展

新增卡牌 → 追加到 `src/data/cards.*.js`（注意 id 前缀约定，见各文件注释）。
新增状态 → `src/data/statuses.js` 加 key，并在 `src/systems/effects.js` 的 `endOfTurnStatuses` / `startTurn` 里接入结算。
新增效果语法 → `docs/DATA_SPEC.md` 有完整白名单，先改契约再改数据。

改完跑一次 `node tools/validate.js` 确认没有破坏引用完整性。
