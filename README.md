# 🏮 焰契 · 锈锚酒馆

> 一款把 **肉鸽跑图 / 回合制卡牌对战 / 酒馆经营** 缝在一起的浏览器游戏。
> 纯原生 ES Module + 零依赖，Node 起一个静态服务器就能玩。

```bash
node server.js
# 打开 http://127.0.0.1:5173
```

> 必须通过 HTTP 访问（用到 ES Module，`file://` 会被浏览器的 CORS 策略拦下）。

自检（数据、导入、战斗、进度、内容、关卡与 UI，全部无需浏览器）：

```bash
npm run check             # 一次跑完下面七步，任何失败都会返回非零退出码
node tools/validate.js     # 数据引用完整性 + 60 场无头战斗模拟
node tools/importcheck.js  # ES Module 导入图完整性
node tools/battletest.js   # 战斗结算、阵营目标、意图预测、药水与首回合加成回归
node tools/progresstest.js # 六幕地图路径、设施等级收入、卡牌升级与存档回读回归
node tools/contenttest.js  # 三个新流派、起手牌组、敌人/事件与内容约束回归
node tools/leveltest.js    # 十二区域、固定编队、区域规则、特殊地点与首领阶段回归
node tools/uitest.js       # DOM 交互、委托操作、完整远征、结算恢复与终局回归
```

单独运行可使用 `npm run check:data`、`check:imports`、`check:battle`、`check:progress`、`check:content`、`check:levels` 或 `check:ui`。这些检查不替代真实浏览器中的布局与交互验证。

当前验证快照（2026-09-30）：数据校验与 60 场模拟通过；导入图 53 模块、367 导入；战斗 33 项、进度 20 项、内容 19 项、关卡 11 项、UI 66 项回归全部通过。关卡回归包含 192 张地图与 2,592 场固定编队模拟。

## 一、这是什么

灰烬潮每隔一夜涨高一寸。你是锈锚酒馆最后一个老板。
一共 **6 夜**，**3 盏灯芯**——每失败一次灭一盏，灯芯耗尽，酒馆沉没。

| 层 | 内容 |
|---|---|
| **经营** | 酒馆跨局保留。设施、员工、局外升级、图鉴解锁；每夜可接一条码头委托，成功交付获得金币、印记与声望。闭门经营产生收入并承受本夜潮汐。 |
| **肉鸽** | 六幕、十二个区域。选旅者与区域 → 预览并选择分支 → 首领 → 结算印记。前三夜分别从第一、第二、第三幕推进至第三幕；后三夜各探索第四、第五、第六幕。种子化生成，可复现。 |
| **卡牌对战** | 基础 3 能量 / 5 抽牌 / 格挡系统 / 30 种状态 / 敌人多阶段意图预告 / 64 件遗物。 |
| **构筑** | 战后三选一、事件拿牌或拆牌、篝火升级或烧牌、商店洗牌、诅咒牌作为代价。 |

## 二、核心循环

```
        ┌──────────────── 酒馆（经营）────────────────┐
        │  设施升级 / 雇佣员工 / 装备 / 图鉴 / 委托    │
        │        「闭门经营」→ 收入 + 本夜潮汐         │
        └───────────────┬────────────────────────────┘
                        │  「出发远征」
              ┌─────────▼──────────┐
              │  选择旅者与区域      │
              └─────────┬──────────┘
        ┌───────────────▼────────────────────────────┐
        │  第 N 幕：分支地图                         │
        │   ⚔战斗  ☗精英  ?异象  ⌂商队  ▲篝火  ◆宝库 │
        │  工坊 / 祭坛 / 补给 / 试炼 / 密库 / 驿站     │
        └───────────────┬────────────────────────────┘
                        │  击败首领；途中首领后选择下一幕区域
              ┌─────────▼──────────┐
              │  结算 → 印记/委托   │ → 回酒馆，进入下一夜
              └────────────────────┘
```

## 三、系统一览

### 战斗
- 每回合 3 能量、抽 5 张，攻击先扣格挡再扣血。
- **格挡**在下一个自己的回合开始时清零；壁垒可让格挡跨回合保留。
- **状态 30 种**：`力量/敏捷/易伤/虚弱/脆骨/中毒/灼烧/荆棘/再生/神器/金属化/仪式/虚化/缠绕/壁垒/回响/专注/坚毅/超载/标记/束缚/迅捷/暴怒/蚀骨/空壳/静电/帷幕/汲取/攻城/碎裂`
  - 中毒无视格挡且逐层 -1；灼烧无视格挡且不衰减
  - 荆棘反弹攻击；神器抵消负面状态；仪式/金属化/再生在回合结算自动生效
- **敌人意图**在玩家回合开始时公布，含伤害数字与台词。精英与 Boss 有多阶段。
- **遗物 64 件**：战斗开始、回合开始/结束、出牌、攻击、格挡、击杀、受伤等钩子，以及攻击、格挡、能量、生命、药水栏位等数值修正。

### 牌组
- 247 张卡牌，4 种类型（攻击 / 技能 / 力量 / 诅咒），5 档稀有度。
- 卡牌升级覆盖降费、数值或效果；战斗与界面共用升级后的定义。
- 新增 72 张分属 **铆钉守势、幽灯狩猎、血誓续战** 的卡牌，每系 24 张，包括 2 张特殊生成/事件牌。
- 8 位旅者具有不同的 10 张起手牌组。战后奖励对角色 `rewardTags` 命中的候选使用 3 倍权重，仍保留跨流派构筑。
- 82 张带 `灰烬印记` 解锁，属于跨局永久内容。

### 委托与经营

- 12 条委托覆盖击杀、精英、探索、用药、拆牌、拿牌、遗物、出牌、伤害、收入、异象和健康归来。每夜基础提供 3 条候选，只能选择 1 条。
- 出发后按真实远征统计记录进度；起始装备带来的卡牌和遗物不计入新获得目标。异象与精英委托会保证至少一条可完成目标的地图路线。
- 全部目标达成且成功归来才发放委托报酬。失败、未达标或闭门经营不发委托奖励；已交付结果存档，刷新不会重复领取。
- 声望在 6 / 15 / 20 时将委托金币倍率提高至 1.1 / 1.2 / 1.3。委托所增加候选和基础报酬。
- 新增药水增效台、委托所、演武场、补给库与 4 位员工。增效只提高支持的战斗数值；自损、金币、最大生命、永久升级和生成牌数量保持原值。

### 区域与特殊地点

- 每幕有两个区域，各有独立场景、真实环境规则、三个专属事件和九个命名遭遇编队。进入节点前可检查敌群、实际生命范围与选项代价。
- 工坊可免费指定升级或付费指定拆牌；祭坛与驿站提供有限场次祝福；补给可选药水、牌袋或钥匙。
- 精英胜利获得钥匙。密库可用钥匙直接开封，也可挑战区域精英获取卡牌与遗物。
- 试炼包含两轮固定敌群，首轮后回复生命且可撤出；两轮全胜获得卡牌、遗物、钥匙及额外 45 金币。

## 六、扩展

新增卡牌 → 追加到 `src/data/cards.*.js`（注意 id 前缀约定，见各文件注释）。
新增状态 → `src/data/statuses.js` 加 key，并在 `src/systems/effects.js` / `battle.js` 的对应生命周期接入实际结算。
新增效果语法 → `docs/DATA_SPEC.md` 有完整白名单，先改契约再改数据。

改完运行 `npm run check`，同时检查数据引用、导入图、战斗规则、进度、内容约束、关卡与界面流程。

存档保存酒馆、解锁、委托选择和已结算报告；进行中的地图、牌组与战斗没有中途续存。
